# Facilitator guide: a 30-minute CodeZoo session

You are there to **watch**, not to teach. The pilot asks whether a child can learn with CodeZoo on their own, so the less you help, the more we learn.

## Before the session

- Signed consent form for every child (see [parent-letter.md](parent-letter.md)).
- Every device passed the [device check](device-checklist.md).
- Pilot recording is on: Grown-ups area → **Take part in a pilot** → Save settings (in a class: teacher's screen → Settings).
- Each child has their own player (picture), and a grown-up has set the child's **age band** in the Grown-ups area (or on the teacher's screen).
- One printed [observation sheet](observation-sheet.md) per child, a pen and a clock.
- Sound off or quiet; chargers nearby.

## Starting (2 minutes)

Say something like:

> "This is a game where you tell an animal what to do. We're testing the game, not you. If something is confusing, that's the game's fault, and it helps us to see it. Just think out loud if you like."

Then let the child open the first level. Note the time on the sheet. The game asks a few questions first: say "just pick what you think, it's fine to guess".

## During (about 25 minutes)

- **Don't touch the screen or the mouse.**
- If the child asks for help, first ask back: "What do you think the monkey will do?" or "What does the game say?" Point to the **Hint** button if they haven't found it.
- Help only if the child has been stuck for about 3 minutes and is getting upset. Then give the smallest hint you can, and mark **"helped"** on the sheet with the level.
- Note anything surprising: what they say, where they hesitate, what they try first, what makes them smile.
- If the child wants to stop, they stop. Mark the time and why.

## Ending (3 minutes)

- If the game hasn't asked yet, let them answer "Would you like to play again?" (the smileys after a solved level), or ask the same question yourself and note the answer.
- Thank them. Ask: "What was the best part? What was annoying?"
- Don't export yet if more sessions follow on the same device.

## After the pilot

In the Grown-ups area (or the teacher's screen): **Export pilot data** → check the list → tick "I agree" → **Save the file**. Send the file and your observation sheets (with no names on them: use the pilot id from the export screen) to the contact in the parent letter.
