# Device checklist

Run this on every device a day or two before the pilot.

1. Open CodeZoo on the device: the family version address in the browser, or the classroom hub address in a class.
2. Open **check.html** on the same address (for example `…/check.html`) and press **Check this device**. It takes about 10 seconds and sends nothing anywhere.
3. Press **Copy the results** and paste them below (or note them by hand).
4. If it says 3D is slow, press **Use the 2D stage on this device**.
5. Turn on **Take part in a pilot** in the Grown-ups area (at home) or on the teacher's screen (in a class).
6. If a child needs it, set **Aa (Look and feel)**: text size, easy-to-read text, high contrast, less motion, big targets.
