          📝 My design card
          What a game program can use
          • def on_key(key): a key was pressed: "up", "down", "left", "right" or "space"
          • def on_tick(): runs on every tick of the clock
          • def on_item(item): the animal arrived on an item
          • def on_touch(critter): a critter and the animal met
          • class Guard(Critter): your own critter; give it an on_tick(self)
          • self.step() self.turn_left() self.turn_around() self.face("up") self.wall_ahead() self.remove() self.x self.y
          • go("left") grab() where() ticks() critters() score.add(1) score.value win() lose()
          • build.block(x, y, "stone") build.clear(x, y) build.item(x, y) build.what(x, y) build with code: stone, water, tree, ice, bridge
          • def on_switch(name): the animal stepped on a switch; it opens or closes the doors called name
          • def on_power(): the animal took a power-up (without it, the critters freeze for a while)
          • door("door").open() door("door").close() door("door").toggle() door("door").is_open()
          • sound("ding") also "boing", "pop", "drum", "whoosh", "tada", "oops", "click"
          • player() animals() playing together: whose animal moves, and where all of them are
